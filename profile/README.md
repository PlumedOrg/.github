# Plumed

Dictée vocale locale pour le français médical : [Plumed](https://github.com/PlumedOrg/Plumed).

Plumed est un fork de [Murmure](https://github.com/Kieirra/murmure) qui ajoute les modèles [UltiMed](https://github.com/UltiMed-Org) et les fonctionnalités de dictée médicale de [parakeet_web](https://github.com/thiswillbeyourgithub/parakeet_web).
